# Khumo Gardens

Official website for Khumo Gardens — a venue offering day visits, accommodation, and events.

**Live site:** [khumo-gardens.vercel.app](https://khumo-gardens.vercel.app)

---

## The problem

Khumo Gardens needed a clean, fast, mobile-friendly website that clearly presented their services, made it easy for visitors to find the venue, and reflected a professional brand. They required a simple way for potential customers to see what was on offer and get in touch.

## What I built

A production React site that includes:

- A services section covering day visits, accommodation, and events
- Localised contact details
- Google Maps integration for real-time directions to the venue
- Fully responsive layout optimised for mobile and desktop
- Strong performance and accessibility scores

## Tech stack

- **React** + **Vite**
- **JavaScript** (ES6+)
- **CSS**
- **Google Maps API**
- **Vercel** (deployment)

## Key decisions

- Chose **Vite** for fast development and optimised production builds
- Used the **Google Maps API** so visitors get accurate, real-time routing instead of a static image
- Focused on performance from the start (code-splitting, asset optimisation, semantic HTML) to hit high Lighthouse scores
- Kept the design simple and content-first so the client’s offerings remain the focus
